## 先确认接入范围

本文面向第三方 Agent Web／Backend 开发者。当前企业入口提供 **EduPlus2 用户 JWT 交换**、**WebSocket turn 执行**，以及有限的会话／资源／语音 HTTP 接口。接口路径可访问不代表任意 Agent 均有调用权限。

第三方 Agent 应代表已验证的用户调用，不得用 URL 中的学校代码、展示名称或自报的 `tenant_id` 取得数据权限。当前没有独立的 Agent client-credentials 授权，也没有可替代 `/api/v1/ws` 的通用 HTTP turn 创建接口。

## 当前已实现与未开放

**当前文档范围：** 15 个第三方 HTTP 接口及 `WS /api/v1/ws` 的 11 个可用命令，均有独立参考页面。Agent 先交换短期 `dt_token`，再通过 WS 发起 turn。

**尚未开放：** 独立 Agent M2M client-credentials、通用 HTTP external turns、OpenAI 兼容聊天接口，以及其他非第三方产品接口。详见[本地版差异](local-differences.mdx)。

## 文档适用范围

本站仅记录第三方 Agent 可使用的已发布契约；部署方仍需提供可访问地址、测试身份与授权范围，本站本身不发放凭证。

Capacity 页面是第三方开发交付物的规范参考，不增加企业公开 API 或安装入口；每类页面均标明当前企业适用状态。
