# 环境与契约边界

部署方会提供服务地址、允许的 Origin、测试用户与授权范围。本文档的 [HTTP 目录](http-api.mdx) 和 [WebSocket 协议](websocket-protocol.mdx) 才是本次第三方 Agent 接入范围；本地开发环境或其他产品页面上出现的路径，不自动成为正式可调用 API。

| 场景 | 第三方开发者应做什么 |
| --- | --- |
| 联调环境 | 使用部署方提供的地址和真实受权测试身份，核对响应与本文档一致 |
| 正式调用 | 代表已验证用户换取 `dt_token`，按当前用户的权限调用 |
| 发现未列出的路径 | 不把它加入 Agent 客户端；向部署方确认是否已发布新契约 |

本站不提供通用 Agent 机器身份凭证，也不承诺本地调试功能在企业环境可用。接口行为变化应以部署方发布的新版本文档为准。不要通过变更学校标识或猜测资源 ID 来绕过授权。
