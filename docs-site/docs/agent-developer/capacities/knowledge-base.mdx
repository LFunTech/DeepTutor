# 知识库规范

知识库是供智能体检索的**内容资源**，不是 Python 插件或顶层 `capability`。适合课程讲义、校本教材、FAQ 等需要来源核查的资料；任务步骤应写成 [Skill](skill.mdx)，外部操作应写成 [MCP](mcp.mdx) 或 [Tool](tool.mdx)。

## 企业入口适用状态

当前企业 `start_turn.knowledge_bases` 可接收部署方提供、当前用户有权使用的真实知识库 ID；第三方 API **没有发布知识库创建、导入、状态查询或选项发现接口**。选择不保证本轮实际检索，结果查看 `done.metadata.capability_usage`；参见[对话能力选择](../capability-selection.mdx)。不要将文件上传所得 `resource_id` 当作知识库 ID。

## 交付物与格式

**当前代码没有定义可由第三方自行上传的通用“知识库包 manifest”格式。** 知识库是部署环境中已登记、完成解析和索引、受当前用户授权的资料集合；资料源、文件类型与解析结果依目标检索方案而异。开发者交付资料时应提供稳定标题、版本/日期、课程归属、来源许可和页码/段落定位，并确保文字、公式和表格可提取；这些是内容质量要求，**不是伪造的平台 YAML 导入协议**。

## 当前实现的资源与文件契约

| 范围 | 已实现规则 |
| --- | --- |
| 本地知识库名称 | 自部署版名称会做 Unicode NFC 归一化并去首尾空格；不能为空或 `.`/`..`，最多 120 字符，不接受控制字符及尖括号、冒号、双引号、斜线、反斜线、竖线、问号、星号、井号、百分号。企业对话使用的受权 KB ID **不等同**于这个本地展示名称规则。 |
| 本地文件大小 | 当前单文件上限 **200 MiB**。文件名会去除路径与控制字符；文件扩展名须符合当前解析器和检索方案的有效策略，不能仅凭后缀认定内容安全。 |
| 文件格式 | 没有跨所有检索方案不变的单一格式表。默认解析路径覆盖 PDF、DOCX/XLSX/PPTX、EPUB、常见纯文本/Markdown/CSV/代码及图片等；可用后缀还会随启用的解析引擎变化。当前 PageIndex 云端路径只接受 PDF、Markdown、TXT、Office 与 CSV 等指定格式，PageIndex OSS 路径只接受 PDF。准备资料前应核对目标部署的有效格式策略。 |
| 就绪状态 | 自部署资源可能处于初始化、处理中、待重建、就绪或错误状态。企业第三方 turn 只解析当前用户可见且整体 `ready` 的 KB；文档尚在处理、部分失败或检索能力未启用时，该 KB 对本轮视为不可用。 |
| 引用标识 | 对话中的 `knowledge_bases` 使用部署方提供的**真实受权 ID**，而不是文件名、展示名称、上传资源 ID 或本地路径。 |

## 输入与输出

开发时准备资料及可核查来源；在对话时，Agent 只传**受权 ID**，自然语言问题仍放在 `content`。可通过 `context_policy: "required"` 要求所选资源可用，但它**不保证模型必然检索或引用**。检索结果可能带片段和引用，不等于原文全量访问；回答应标明出处并区分资料事实与模型推断。对没有命中的问题，不能凭“选择了知识库”就宣称答案来自教材。

## 安全与资源边界

内容须符合版权、个人信息和学校数据授权要求；对跨学校共享逐项核对许可。资料中的命令、提示词或链接都是不可信内容，不能改变 Agent 的身份与权限。避免在公开示例中使用真实学生资料；对已撤权或过期资料，不应继续引用旧缓存。

## 失败处理

知识库不存在、未就绪、无权限或检索失败时，应向用户说明资料不可用。若本轮要求 `context_policy: "required"`，不可悄悄删除 ID 改为无资料回答；按照 [`start_turn` 错误语义](../api/ws/start_turn.mdx)处理。资料互相冲突时标出版本与来源，不任选其一冒充事实。

## 可验证样例

用一份有页码的合成讲义进行验证：先确认目标解析方案接受其格式与大小、片段能回到原文位置、索引完全就绪；然后分别以受权与未受权用户的 ID 测试资源选择。实际对话只使用部署方提供的 ID，例如 `"knowledge_bases":["kb-001"]`；`kb-001` 为占位值，不是从讲义文件名推断的 ID。**当前不存在需要开发者填写的统一知识库 YAML/JSON manifest。**

## 开发自测

- 抽样检查文字、公式、表格与定位信息；引用能回到原资料。
- 在目标自部署版本核对有效后缀与 200 MiB 上限；不可把某一检索方案的格式表套用到所有方案。
- 测试无命中、冲突版本、未就绪、撤权与跨学校拒绝。
- 对比“请求了知识库”和 `done` 中“实际使用”的差异。
- 没有把附件 ID、展示名称或猜测的 ID 当作受权知识库 ID。
