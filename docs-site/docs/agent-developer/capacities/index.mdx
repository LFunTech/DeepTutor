# Capacity 开发规范

本目录面向编写扩展的第三方开发者，包括学校开发团队。这里的 **Capacity** 是“增强智能体可用能力”的统称，不等于 WebSocket 请求里的顶层 `capability` 字段。请选择与交付物相符的一类规范。

各独立页面按**当前 DeepTutor 代码实际支持的契约**列出入口、字段、取值、限制、结果和失败语义；示例仅用于验证格式，不代替规范。自部署扩展协议与企业第三方正式 API 分别标注，不把规划中的能力或未开放的安装方式写成现状。不同部署版本可能变化，交付前应按目标版本复核。

**开发规范不等于企业入口已开放安装或调用。** 当前企业第三方可调用范围仍以 [HTTP API 目录](../http-api.mdx)、[WebSocket 命令](../websocket-protocol.mdx)为准；对话请求目前只支持顶层 `chat`，受权知识库和 Skill 可按 [对话能力选择](../capability-selection.mdx)传 ID。非空外部工具选择、其他顶层能力和扩展安装均不能据本目录推定为可用。文档只谈如何开发与验证交付物，不描述发布或管理流程。

**现在可以做的事：** 按下列页面准备和本地验证交付物；在企业第三方对话中，仅能使用部署方提供的、当前用户有权引用的知识库/Skill ID。其余类型须先向部署方确认适用版本及接入条件，不应直接写进生产 Agent 的可调用能力列表。

## 选择要开发的类型

| 你要交付什么 | 阅读规范 | 与一次对话的关系 |
| --- | --- | --- |
| 向智能体提供远程系统操作的标准服务 | [MCP Server](mcp.mdx) | 通过 MCP 工具协议提供操作；当前企业 turn 不开放非空选择 |
| 一个由模型按需调用的单次函数 | [Tool](tool.mdx) | 单次调用，不独占整个 turn |
| 描述任务步骤和使用约束的指导材料 | [Skill](skill.mdx) | 当前企业 turn 可选择受权 Skill ID；选择不保证采用 |
| 可供检索的课程或教学资料 | [知识库](knowledge-base.mdx) | 当前企业 turn 可选择受权知识库 ID；不是代码插件 |
| 接管完整一轮对话的多阶段能力 | [自定义 Agent／Turn Capability](turn-capability.mdx) | 属于顶层能力；当前企业仅开放 `chat` |
| 在 `chat` 过程中增补提示与专属工具 | [对话循环扩展](loop-extension.mdx) | 不是新的顶层 `capability` |
| 新的可视化产物和呈现方式 | [可视化扩展](visualizer.mdx) | 不是直接调用的企业 WS 命令 |
| 阅读材料上的交互动作 | [阅读扩展](reading-extension.mdx) | 属于阅读场景，不是通用对话选择 |
| 有独立可执行命令的应用 | [CLI 工具集成](cli-app.mdx) | 属于受控命令工具，不是 `exec` 权限授权 |

## 共同规则

1. **明确输入、输出、失败。** 给出稳定名称、参数或内容结构、错误语义、超时和重试/幂等策略；不要让失败看起来像成功。
2. **最小权限。** 对用户、学校与资源进行授权；不要把提示词、文件名、URL 参数或客户端声明当作授权凭据。外部内容和工具结果均是不可信数据。
3. **可验证。** 使用合成资料覆盖正常、无权限、缺失、超限、超时、重复请求与恶意输入；不要在示例中填真实密钥或他人资源 ID。
4. **确认适用环境。** 本地/自部署可用的扩展格式并不自动进入企业运行环境。部署方未明确开放时，第三方 Agent 不应依赖该扩展执行。

## 不属于本目录的对象

Partner／消息频道是通讯入口，模型 Provider 是推理服务配置，turn 附件是一次请求引用的资源，均不等于可选的顶层 `capability`。附件应按[资源上传接口](../api/http/upload-intent.mdx)和 [`start_turn`](../api/ws/start_turn.mdx) 使用；不要将附件 ID 当知识库或 Skill ID。
