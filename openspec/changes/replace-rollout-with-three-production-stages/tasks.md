# 实施任务：三个里程碑、七个工作包（尚未执行）

本次在既有顺序上细化企业扩展包/外壳与 LightRAG Server 的实施责任和验收，保留 86 项任务编号、完整业务范围及全部未完成状态；不新增里程碑或把包外实现当作无需开发。A3 包内顺序继续覆盖实际流水线交付。1–7 组分别对应 A1/A2/A3/B1/B2/C1/C2，8 组是跨里程碑的 H 工作线，不是第八个业务工作包。

范围/依赖/门禁主说明见 [02](../../../docs/eduplus2-integration/02-rollout-testing-and-migration.md)。每个行为任务包含适用的 migration、真实调用、权限/异常/并发测试及切换说明；不能只写一个 Store 或页面就勾选。基础设施任务以真实命令和集成环境证据验收。

**依赖**：A1 契约确定后 A1/A2 可并行；A3 的 Woodpecker 开发与部署准备从 A1 开始，最终 G1 等待 A1+A2。B1 外部准备提前并行，接入验收使用 M1 基线；B2 依赖 B1；C1 依赖 M2 治理服务；C2 可在 C1 契约稳定后开发，最终 G3 等待 C1+C2。任意发布启用多执行者/承诺 HA 之前完成 G-H；仅发布单执行模式不能将未做的 H 多副本任务勾选。

**执行导航**：组号表示工作包归属，各组内按执行顺序排列；不是做完第 1/2 组才开始第 3 组。A1 启动时同时开展 3.1–3.4 环境/CI 准备、4.1 外部契约和 8.1/8.2 目标/可靠性工作；3.5–3.9 随 A1/A2 实现持续集成，3.10–3.14 汇总完整功能及故障验收，3.15 生产放行，3.16 实际发布与最终确认。领域设计见 [05](../../../docs/eduplus2-integration/05-woodpecker-kubernetes-pipeline.md)，不另增业务工作包。
